# 项目总览

## 子衿是什么

子衿是一个基于 PyQt6 + Live2D 的桌面伴生代理，让虚拟角色成为用户的桌面伴侣。

## 核心理念

```
用户输入 → Agent协调 → LLM思考 → 情感提取 → 动画反馈 → 记忆存储
```

## 技术栈

| 模块 | 技术 |
|------|------|
| 界面 | PyQt6 + OpenGL |
| 角色 | Live2D Cubism SDK |
| 大模型 | Ollama / OpenAI API |
| 记忆 | ChromaDB 向量数据库 |
| 语音 | pyttsx3 |

## 版本管理

版本号定义在 `version.py`，格式为 `主版本.次版本.补丁`：

```
0.1.0  ← 当前：初始开发阶段
0.2.0  ← 功能基本完成
1.0.0  ← 首个正式发布
```

**使用方式：**

```python
# 在代码中引用版本
from version import __version__
print(f"子衿 v{__version__}")
```

**发版流程：**

1. 修改 `version.py` 中的 `__version__`
2. 打 git tag：`git tag v0.2.0`
3. 运行 `python build.py` 打包
